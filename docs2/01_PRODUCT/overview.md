# Обзор продукта (TO BE)

**Дата среза:** 2026-08-31. Источник: ПЗ §1–§5, §26, §28. Реализация: `NOT_STARTED` — см. [status.md](../03_IMPLEMENTATION/status.md).

## Проблема

Аналитик, отслеживающий макропруденциальное регулирование, вручную обходит десятки сайтов центральных банков и надзорных органов, чтобы ответить на один вопрос — например, перешёл ли регулятор к positive-neutral подходу при установке контрциклического буфера капитала. Нужная информация редко лежит на странице с очевидным названием: она находится в методологическом PDF, приложенном к странице про совсем другой инструмент. Ручной поиск не масштабируется и не оставляет воспроизводимого следа источников.

## Что делает система

Принимает исследовательский вопрос и список стартовых URL. Проходит цепочку

```
Research Question + Seed URLs
  → проверка доступности URL
  → загрузка страницы
  → разбор контента
  → извлечение ссылок
  → классификация ссылок
  → загрузка релевантных HTML/PDF (depth ≤ 2)
  → извлечение текста
  → оценка релевантности вопросу
  → извлечение evidence
  → структурированный результат
```

Возвращает два артефакта (ПЗ §27): машиночитаемый `research_result.json` и человекочитаемый `research_report.md`, в которых каждый существенный факт снабжён ссылкой на источник, а для PDF — номером страницы.

Детальный сценарий — [workflow.md](workflow.md).

## Ключевая ценность

Система должна находить первоисточник, до которого нельзя дойти по совпадению названия. Эталонная проверка (ПЗ §25, REQ-031): на вход подаётся **только** страница CNB про буфер системного риска и вопрос про positive-neutral CCyB. Ожидаемый путь:

```
SyRB page → SyRB methodology PDF → "standard CCyB rate (or positive neutral rate)"
```

Ни страница, ни вопрос напрямую не совпадают: связь чисто семантическая. Это и есть проверяемая гипотеза этапа 1.

## Предметная область

Макропруденциальное регулирование. Термины, вокруг которых строятся тестовые вопросы (ПЗ §3, §23): CCyB (контрциклический буфер капитала), positive-neutral / positive cycle-neutral CCyB, standard CCyB rate, neutral rate, releasable capital. Материалы `source/links.md` дополнительно покрывают буфер консервации капитала, буфер системного риска (SyRB), системно значимые организации (D-SIB / O-SII), заёмщико-ориентированные меры (LTV / DSTI / DTI / LTI) и ликвидность (LCR / NSFR).

Из `source/links.md` (строка 5) взята единственная методологическая справка, доступная в репозитории: D-SIB и O-SII преследуют одинаковую экономическую цель — дополнительный буфер капитала для системно значимых участников; различие в происхождении термина (D-SIB — Базельский комитет, O-SII — законодательство ЕС и Великобритании, CRD/CRR, охватывает не только банки); на практике O-SII является европейским аналогом D-SIB.

**Важно:** система не вычисляет буферы, не интерпретирует регуляторные нормы и не разрешает противоречия между источниками (ПЗ §26). Она находит и цитирует. Предметная терминология нужна только как вход для семантической оценки и как материал тестового датасета.

## Чем система не является

По ПЗ §2 и §26 система на первом этапе:

- не заменяет Deep Research агент;
- не гарантирует полноту исследования;
- не ищет новые сайты через поисковые системы;
- не находит все источники по стране;
- не строит knowledge graph;
- не определяет истину при конфликтующих источниках;
- не поддерживает десятки форматов;
- не выполняет постоянный мониторинг.

## Направление развития после MVP

ПЗ §28 задаёт последовательность: MVP crawler → semantic document discovery → hybrid retrieval → reranker → multi-agent research → cross-source verification → temporal reasoning → knowledge graph → scheduled monitoring → production research platform.

Прямое указание ПЗ §28: эти функции **не должны усложнять первый этап разработки**. Архитектура при этом обязана допускать их добавление (REQ-033).
