# ADR-001. Вывод группы (P-4-like inference) выполняется до P-3

**Дата:** 2026-09-02. **Статус:** ACCEPTED. **Область:** `app/taxonomy.py`.

## Контекст

Порядок правил классификации: P-0, P-1, P-2, P-3 (навигация), P-4 (разрешение
обобщённого anchor по контексту), P-5, P-6 (матрица).

P-3 присваивает `NAVIGATION` при одновременном выполнении условий, одно из
которых — **«группа ∈ {navigation, related_material, отсутствует}»**. То есть
P-3 не может быть вычислено, пока группа неизвестна.

Для ссылок с обобщённым или пустым anchor (`Download`, `More information`,
`Link`, `""`) группа не выводится из anchor вообще — она берётся из
`section_heading`, затем `surrounding_text`, затем URL path. Это и есть
P-4-like inference.

Буквальный порядок «P-3, затем P-4» делает кейс LC-17 недостижимым:
`More information` → внешний неавторитетный домен, подвал, контекст без группы.
P-3 сработал бы первым и вернул `NAVIGATION`, тогда как датасет требует
`UNKNOWN`.

## Решение

Вывод группы по контексту выполняется **до** P-3.

Порядок в реализации: P-0 → P-1 → P-2 → **вывод группы** → P-3 → P-5 → P-6.

## Обоснование и границы

* **Это feature derivation, а не правило классификации.** Шаг вычисляет
  признак «группа» — тот же, что P-6 использует в матрице. Он ничего не
  решает о ссылке, он делает предусловие P-3 вычислимым.
* **Это не повышение приоритета P-4 над P-3.** Приоритет правил не менялся:
  P-3 по-прежнему срабатывает раньше P-5 и P-6 и по-прежнему перекрывает
  матрицу. Изменился момент вычисления входного признака, а не порядок
  принятия решений.
* Единственный класс, который шаг выдаёт сам — `UNKNOWN`, и только когда ни
  заголовок, ни окружающий текст, ни URL, ни расширение файла не дают группы.
  Это ровно та формулировка, что уже записана в P-4.
* **Причина:** сделать LC-17 достижимым и не классифицировать generic-ссылки
  подвала как навигацию. `More information → https://vendor.example/tools/` —
  не элемент структуры сайта; о нём попросту ничего не известно, и правильный
  ответ «признаков недостаточно», а не «служебная ссылка».

## Следствия

* LC-17 проходит; на MNB CCyB появился 1 `UNKNOWN` (0,6 % ссылок, порог ≤ 10 %).
* Обобщённый anchor с определимой по контексту группой ведёт себя как раньше:
  `Download` на `ccyb-methodology-q42024-en.pdf` в подвале остаётся `HIGH_VALUE`
  (расширение документа отдельно блокирует P-3).
* Нумерация правил в утверждённой спецификации осталась прежней и расходится с
  порядком вычисления. Расхождение зафиксировано в docstring `app/taxonomy.py`
  и подлежит уточнению при следующем возврате к БА. Матрица, перечень классов и
  перечень групп не менялись — полномочие maintainer'а не превышено.
