## Открытая проблема: 111 кандидатов из 158

**Это не дефект taxonomy.** Классы присвоены по матрице верно, датасет зелёный,
первоисточники на месте.

Разбор: 30 кандидатов из 111 — пункты мега-меню `/financial-stability/*` и
`/macroprudential*`. Группа `topic_landing` (secondary) + `partial` по URL →
`POTENTIALLY_RELEVANT`. Правило навигации их намеренно не отбрасывает: оно
применяется только к группам `navigation`, `related_material` и к ссылкам без
группы. Это записано в спецификации осознанно — потерять раздел предметной
области дороже, чем загрузить лишний документ.

Ещё 13 — self-links и кнопки «поделиться», ведущие на саму seed-страницу.
Они отсеиваются множеством посещённых URL на стороне обхода, а не классификатором.

Ужесточать правила ради снижения этого числа нельзя: любое такое изменение
ломает LC-кейсы или теряет первоисточники. Ограничитель — политика обхода и
бюджет документов.
